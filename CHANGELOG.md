# Changelog

## 2.0.0

First release.

- **Attenuverter:** polyphonic attenuverter with DC offset (3HP).
- **Piano Roll:** clickable piano roll sequencer (30HP).
  - 1–4 voices, each with its own color, select button and octave control. V/Oct and gate outputs are polyphonic.
  - Loop of 1–16 bars with 1–8 beats per bar. An overview strip shows the whole loop and scrolls the grid.
  - Scale and root settings. Rows outside the scale are blocked, and existing out-of-scale notes snap to the scale when played.
